مشروع Rory Anniversary Website

محتويات المجلد:
- index.html : الصفحة الرئيسية
- style.css : ألوان وتنسيق الموقع
- script.js : التفاعلات ومشغل الأغاني
- images/ : الصور الخمس التي أرسلتها

للتجربة:
افتح index.html في متصفح بعد فك ضغط الملف. مشغل YouTube يحتاج إنترنت.

للرفع على GitHub:
1) أنشئ Repository جديد باسم rory-anniversary (واجعله Public إذا كنت ستستخدم GitHub Pages المجاني).
2) ارفع محتويات هذا المجلد كلها، وليس ملف ZIP نفسه.
3) من Settings > Pages اختر Deploy from a branch ثم main و /(root).
4) انتظر نشر الموقع وافتح الرابط الذي يعطيك GitHub.

ملاحظة خصوصية:
أي شخص لديه رابط موقع GitHub Pages العام يمكنه مشاهدة الصور والرسائل. لا تضفوا بيانات خاصة أو صورًا لا تريدون مشاركتها.
